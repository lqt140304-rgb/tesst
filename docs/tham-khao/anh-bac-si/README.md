# Ảnh bác sĩ trưởng

`bac-si-truong.png` — ảnh "Bác sĩ trưởng Lê Thái Sơn" chủ dự án gửi (20/10/2026). Ảnh **có chữ in sẵn** ("BÁC SĨ TRƯỞNG · Lê Thái Sơn · Đồng hành cùng thú cưng mỗi ngày."); trên web nên dựng chữ bằng văn bản thật, nên cắt bỏ phần chữ hoặc xin ảnh không chữ (thiết kế làm lại §7).

Để riêng thư mục này (không để trong `../anh/`) vì `scripts/photos.py` biến mọi ảnh trong `../anh/` thành ảnh thú cưng.
