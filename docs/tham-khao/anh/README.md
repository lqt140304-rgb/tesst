# Ảnh thú cưng của chủ dự án (20/10/2026)

`scripts/photos.py` biến mỗi ảnh ở đây thành `src/assets/img/pet-<tên tệp>-{avatar,card,banner}.webp`; tên tệp = `photo_key` trong dữ liệu mẫu.

| Tệp | Ảnh | Gán cho bé |
|---|---|---|
| `meo-trang-ngu.jpg` | Mèo trắng ngủ trên máy ở bệnh viện | Miu (chị Lan, đang nội trú) |
| `poodle-nau-xe.jpg` | Poodle nâu trong xe | Bông (chị Lan) |
| `poodle-nau-chuong.jpg` | Poodle nâu ở khu chuồng | Mochi (đang nội trú) |
| `pom-trang.jpg` | Pomeranian trắng | Mít (Phốc sóc) |
| `meo-trang-gang-tay.jpg` | Mèo trắng đội găng tay | Na |
